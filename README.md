# Ohm

A clickable prototype of a mobile web app that reads, checks and pays a large Indian business electricity bill, built for a Neufin take-home design assignment.

- Live prototype: https://mindninjax.github.io/ohm/ (open it on a phone, or on a laptop where it shows inside a phone frame)
- Designs: Figma file "Bill app"
- App: `app/` (Vite, React 19, TypeScript, Tailwind CSS 4, Motion). Everything is simulated: no backend, no real payment.

```bash
cd app
npm install
npm run dev
```

The example bill uses sample names (Harbourline Hotels, Northgrid Electric). Every number comes from `specs/round2/DATA.md`.
