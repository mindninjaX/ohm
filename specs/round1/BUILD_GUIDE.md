## Hard-won gotchas (follow these)
1. `figma_execute` times out at 30 s, but the code can KEEP RUNNING in the background after the timeout. After a timeout: wait (a call that sleeps 8 to 12 s), then inspect what exists, then continue. Make every step idempotent (check by name before creating) so a re-run never duplicates. Keep each call small (one card or a few nodes).
2. The first import of any library asset (component, style, variable) can take 10 to 20 s. Pre-import what you need early with background promises (start them, don't await) and poll.
3. A paint from `figma.variables.setBoundVariableForPaint(paint,'color',variable)` keeps a fallback `color`. Overrides inside instances RENDER THE FALLBACK. Always pass the token's real colour as the base colour (use the hex above). Paints are frozen objects: to set opacity, build a new object `{type:'SOLID', color, opacity, boundVariables: p.boundVariables}`; for overlays prefer layer opacity.
4. Instance sublayers cannot be moved, resized-by-position, or rotated (relative transform). Use component swaps (`swapComponent`), variant changes (`setProperties`), visibility, or overlays in a wrapper frame.
5. Plugin reloads wipe `globalThis`. If you install helpers on `globalThis`, use your own namespace (e.g. `globalThis.OHM_S05`) and reinstall when missing. Never overwrite `globalThis.OHM` (used by the lead).
6. Text in kit instances: load the node's fonts (`getRangeAllFontNames`) before setting `characters`. Prefer component TEXT properties when they exist.
7. Auto layout: set `layoutSizingHorizontal = 'FILL'` only after appending to an auto-layout parent. `resize()` on an auto-layout frame fixes its size; set `primaryAxisSizingMode`/`counterAxisSizingMode` back to 'AUTO' to hug.
8. `findOne(n => n.name.startsWith('Bar '))` style matching can catch the wrong node; match by type too.
9. Prototype: `await node.setReactionsAsync([{trigger:{type:'ON_CLICK'}, actions:[{type:'NODE', destinationId, navigation:'NAVIGATE', transition:{type:'SMART_ANIMATE', easing:{type:'EASE_OUT'}, duration:0.25}, preserveScrollPosition:false}]}])`. Back: `actions:[{type:'BACK'}]`. After delay: trigger `{type:'AFTER_TIMEOUT', timeout:1.5}` on the frame. Reactions on layers nested inside instances work. Overlay-style sheets are separate full frames (the dimmed background is a clone of the screen underneath, named `<frame> (behind)`, with its reactions stripped).
10. Screenshots: `figma_take_screenshot` with nodeId and scale 1 (or 0.5 for quick checks). Check against the spec after each frame. Max 2 fix rounds per frame, then note what is off.
11. Fonts: Inter via the library styles; SF Pro only inside iOS kit parts.
12. Run a duplicate-text scan on your frames at the end (repeated identical text layers usually mean a timed-out call ran twice).
